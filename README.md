# AI Guided Resource Strategy Simulation

This example simulates a strategic resource gathering scenario involving 6 "humans" (agents). Each human employs a specific "stratagem" (tactic) to collect resources from a shared pool. One human uses an "AI-powered" strategy, which dynamically selects the most appropriate base stratagem based on the current game state, demonstrating how AI can augment human decision-making in complex strategic environments.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
